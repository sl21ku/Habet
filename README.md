# Habet (ハビット・ベット)

自分の「良い習慣（早起き、筋トレ、勉強）」に仮想チップを賭け、達成できたら倍になって返ってくるセルフ・ベッティング iOS アプリです。

## 開発環境

- Xcode 15以上
- iOS 17以上
- XcodeGen

## セットアップ

```sh
xcodegen generate
open Habet.xcodeproj
```

`project.yml` の `bundleIdPrefix`、App Group、署名チームはご自身の Apple Developer アカウント設定に合わせて変更してください。
本アプリでは、メインアプリと Widget / Live Activities 拡張機能が連携するために App Group (`group.com.sl21ku.Habet`) を使用しています。

## 実装済みの範囲

- **SwiftUI & SwiftData による習慣ベット管理**:
  - アクティブなベットの進行状況、締め切り、オッズの管理。
  - カメラ撮影（シミュレート）による完了証明写真撮影フロー。
  - 過去のベット成功・失敗の履歴リストと勝率の統計ダッシュボード。
- **カジノミニゲーム**:
  - **ラッキースロット**: 3つのリール（🎰, 💎, 🔔, 🍒, 🍋, 💩）による本格遅延停止アニメーション付きスロット。🎰が揃うジャックポットで特別テーマ/アバターが即座にアンロック。
  - **ブラックジャック**: 52枚のデッキシャッフル、Hit、Stand、Double Down、Aの値の自動調整（11/1変換）をサポートする本格対局テーブル。
- **ショップシステム**:
  - 貯まったチップを消費して、「ゴールド VIP」「サイバーネオン」「OLED ダーク」といったカラーテーマや、「ロイヤルチャレンジャー」「ハイローラー」「ラッキーキャット」などのアバター/称号を獲得・装備可能。
  - 選択したテーマがアプリ全体の背景グラデーションや配色に即座に適用されます。
- **プロフィール & ユーティリティ**:
  - 賭け成績、成功・失敗回数、勝率スタッツの表示。
  - テストプレイが円滑に行えるよう「デモチップの獲得 (+200)」ボタンと、データベースを初期化する「データリセット」ボタンを配置。
- **Core Haptics（触覚フィードバック）**:
  - スロットの回転時、リール停止の瞬間、ベット成功時のファンファーレ、失敗時のエラー振動などを `HapticService` 経由で演出。
- **Lock Screen Widgets / Live Activities**:
  - `ActivityKit` を用いて、習慣ベットの残り時間（ライブタイマー）や賭けているチップの状況をロック画面・Dynamic Island にリアルタイムに表示。
- **GitHub Actions での CI テスト検証**:
  - ユニットテスト (`HabetTests`) でモデルの動作やブラックジャックの点数判定ロジックを検証。
  - UIテスト (`HabetUITests`) でメインタブ遷移やプリセット選択イベントを検証。
